# 1. What was the breakthrough that moved the work forward?

Managing the context window by exporting conversations/plans to md files not only made sessions with Claude much more efficient, but also more automated. This was as, the greater focus of the context window being on the deliverable, allowed for more in-depth work on it to be done, needing less intefering from me to guide the context back to where it needed to be.

# 2. What did this work change about who I want to be as a software developer?

I started this crit off with exploring games I use to play as a child, taking note of how intuitive the controls and mechanics were. This crit has made me realise the impact time spent on considering user experience alone can have on the end goal - something which felt overlooked when working on, and getting burned out by, technical detail. As a software developer, this work has made me feel like I can now express my creative thoughts more freely, without being bounded/tired out by technical work.
